# Expediente de pruebas

Este expediente aplica de forma proporcional ISO/IEC/IEEE 29119 al proyecto. Complementa el [plan de pruebas general](../11_plan_de_pruebas.md).

| Archivo | Uso |
|---|---|
| [01_estrategia_y_plan_pruebas.md](01_estrategia_y_plan_pruebas.md) | alcance, riesgos, niveles, ambiente y criterios |
| [02_especificacion_casos_prueba.md](02_especificacion_casos_prueba.md) | trazabilidad y técnicas de los casos |
| [03_registro_ejecucion_pruebas.md](03_registro_ejecucion_pruebas.md) | resultado automatizado del 2026-07-03 y formato manual |
| [04_registro_incidencias.md](04_registro_incidencias.md) | clasificación y seguimiento de defectos |
| [05_informe_cierre_pruebas.md](05_informe_cierre_pruebas.md) | estado actual y decisión de liberación condicionada |

El resultado automatizado cubre lógica de servicios. No reemplaza pruebas en dispositivo, interfaz, SQLite real, seguridad, rendimiento ni aceptación de usuarios.
