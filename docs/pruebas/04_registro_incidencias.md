## Clasificación

- **Crítica:** pérdida/corrupción de datos, acceso grave o aplicación inutilizable.
- **Alta:** flujo principal incorrecto sin alternativa segura.
- **Media:** función secundaria afectada o existe alternativa controlada.
- **Baja:** defecto visual, texto o mejora menor.

## Flujo de estado

Nuevo → analizado → asignado → corregido → listo para reprueba → cerrado. Si la evidencia no confirma la corrección, reabrir. Una decisión “no corregir” requiere justificación y aceptación explícita del riesgo.
