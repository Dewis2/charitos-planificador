# Mapa de procesos AS-IS / TO-BE

**Código:** INS-11  
**Versión:** 1.0  
**Técnica:** entrevista, observación y modelado de procesos

## AS-IS propuesto para validar

1. Personal revisa ventas, sobrantes y experiencia reciente.
2. Taller y encargados acuerdan cantidades por canales informales u hojas.
3. Taller produce y distribuye entre Tienda Chica y Tienda Grande.
4. Cada tienda vende y registra parte de la operación.
5. Sobrantes/malogrados se anotan en Google Sheets u otros soportes.
6. El análisis se realiza de forma manual y tardía.

Problemas a confirmar: registros dispersos, nomenclatura inconsistente, baja trazabilidad, mezcla de pedidos con vitrina y decisiones dependientes de experiencia individual.

## TO-BE de la app actual

1. Mantener catálogo y parámetros del producto.
2. Importar o registrar stock, producción, ventas, merma y pedidos.
3. Calcular demanda heurística con historial disponible.
4. Calcular stock vendible, merma esperada y lote de producción.
5. Mostrar recomendación de vitrina y pedidos confirmados por separado.
6. Registrar producción y crear lotes con vencimiento.
7. Consumir lotes por FEFO al vender o mermar.
8. Consultar reportes y exportar CSV.

## TO-BE futuro planteado en la tesis

Añade usuarios/roles, backend, base centralizada, modelo ML, API predictiva, variables calendario, log de aceptación/modificación y evaluación de MAE/RMSE/MAPE. Estos componentes no pertenecen todavía a la línea base implementada.
